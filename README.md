Women's Safety Band using LoRa Technology
* Overview

This project is a wearable emergency safety band designed for women. The system uses LoRa technology to transmit SOS alerts along with GPS coordinates without depending on mobile networks.

* Features
‌

Emergency SOS button

‌

GPS location tracking

‌

Long-range LoRa communication

‌

LED and buzzer feedback

‌

Receiver-side alert notification

‌

Low power design

‌

‌

‌

‌

* Working
‌

User presses the emergency button.

‌

ESP32 reads GPS coordinates.

‌

Coordinates are transmitted using LoRa.

‌

Receiver receives the SOS message.

‌

Receiver extracts latitude and longitude.

‌

Alert LED blinks indicating emergency notification.
